# Handoff: 디스크닥터(Disk Dr.) 허리보조기 랜딩페이지

## Overview
디스크닥터 허리보조기(WD57 / WD37) 제품 소개 및 **온라인 판매·제품 문의 접수**를 목적으로 하는 단일 페이지 랜딩페이지. 전화/이메일/주소 등 오프라인 접점은 노출하지 않으며, 문의는 페이지 내 폼으로만 접수한다.

## About the Design Files
`design/` 폴더의 파일은 **HTML로 만든 디자인 레퍼런스(프로토타입)**다. 그대로 배포하는 프로덕션 코드가 아니라, 의도한 레이아웃·타이포·색상·인터랙션을 보여주는 문서로 취급한다.
구현 시에는 대상 코드베이스의 기존 환경(React / Next.js / Vue 등)과 컴포넌트·스타일 패턴을 사용해 **이 디자인을 재현**한다. 아직 환경이 없다면 프로젝트에 적합한 프레임워크를 선택해 구현한다.
`design/Disk Doctor 랜딩페이지.dc.html`는 사내 프리뷰 런타임(`support.js`)에 의존한다. 마크업/스타일 값만 참조하고 런타임 자체는 이식하지 않는다.

## Fidelity
**High-fidelity.** 색상·폰트·간격·상태값이 확정된 상태이므로 픽셀 수준으로 재현한다. 단, 이미지는 클라이언트 제공 원본으로 교체 가능하다.

## Interactions & Behavior

### 문의 폼
필드 순서와 규칙:
1. **이름** — text, placeholder `홍길동`. (필수 아님)
2. **연락처** — `inputMode="numeric"`, maxLength 13, placeholder `010-0000-0000`. 입력 시 숫자만 남기고 **자동 하이픈**:
   - 3자리 이하: 그대로
   - 4~7자리: `XXX-YYYY`
   - 10자리: `XXX-YYY-ZZZZ`
   - 11자리: `XXX-YYYY-ZZZZ` (최대 11자리 절삭)
3. **회신받을 이메일** — `type="email"`, placeholder `name@example.com`. 정규식 `^[^\s@]+@[^\s@]+\.[^\s@]+$`. 값이 있고 형식이 틀리면 보더 `#c0453f`.
4. **문의 유형** — 단일 선택 pill 버튼 4개: `제품 사용 문의`(기본), `사이즈 상담`, `매장·병원 공급`, `A/S 문의`. 선택 시 배경 `#175c63` + 흰 글씨, 미선택 시 흰 배경 / 보더 `#dcdfde` / 글자 `#4a5254`. 높이 40px, radius 999px.
5. **관심 제품** — 단일 선택 버튼 3개(동일 색 규칙, 높이 44px, radius 8px, flex:1): `WD57`(기본), `WD37`, `미정 / 상담`.
6. **문의 내용** — textarea 4행, placeholder "사이즈, 수량, 납기 등 필요한 내용을 적어 주세요.", resize vertical.
7. **개인정보 동의 체크박스** — accent-color `#175c63`, 라벨 "문의 처리를 위한 개인정보 수집 및 이용에 동의합니다."
8. **문의 보내기** 버튼 — 높이 54px, radius 10px, `#175c63`, hover `#0f3f45`.

**검증 규칙**
- 연락처(숫자 10자리 이상)와 이메일(형식 유효) **중 하나만 있으면 통과**. 둘 다 없으면 제출 불가.
- 이메일이 입력되어 있는데 형식이 틀리면 제출 불가.
- 안내 문구는 필드 아래 12.5px 텍스트로 상시 노출: 기본 `#8a908f`, 제출 시도 후 실패면 `#c0453f`.
  - 미입력 시: "연락처 또는 이메일 중 한 가지는 반드시 입력해 주세요."
  - 이메일 형식 오류 시: "이메일 주소 형식을 확인해 주세요. (@ 포함)"
- 프로토타입에서는 개인정보 동의 체크가 제출 조건에 포함되어 있지 않다. **실제 구현에서는 필수 체크로 처리 권장.**

**제출 성공 상태** — 폼 카드가 성공 뷰로 교체(min-height 420px, 중앙 정렬): 52px 원형(`#e3edee` 배경, `#175c63` 체크) + `문의가 접수되었습니다`(700/20px) + "영업일 기준 1일 이내에 남겨주신 연락처로 담당자가 연락드리겠습니다." + `다시 작성하기` 버튼(폼 초기화).

**서버 연동은 미구현.** 백엔드 엔드포인트(POST 문의 저장 + 담당자 알림 메일/알림톡)를 붙여야 한다. 전송 payload 권장: `{ name, phone, email, inquiryType, model, message, agreedAt }`.

## State Management
- `name`, `phone`, `email` — 폼 입력값(제어 컴포넌트). `phone`은 저장 전 포맷터 통과.
- `type` — 문의 유형, 기본 `'제품 사용 문의'`.
- `model` — 관심 제품, 기본 `'WD57'`.
- `touched` — 제출 시도 여부. true일 때만 오류 색상 노출.
- `sent` — 제출 완료 여부. true면 성공 뷰 렌더, `다시 작성하기`로 전체 초기화.
- 데이터 페칭 없음. 제출만 서버 연동 필요.
